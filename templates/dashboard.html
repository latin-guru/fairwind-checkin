Suggested HubSpot Active Lists

In a live portal these are active segments that update themselves. A PM would open Marketing → Ads and create a contact segment audience from each targeting list, so it syncs to Meta, Google or LinkedIn. Every targeting list starts from the same consent rule, so a guest who didn't opt in, or who opted out, is never in an ad audience.

Honest limit: ad platforms need much bigger audiences than 50 sample rows before they'll match (roughly {% for name, n in segments_minimums %}{{ name }} {{ "{:,}".format(n) }}{% if not loop.last %}, {% endif %}{% endfor %}). The value here is the property model, the consent rules and the list design.
How it reaches Meta and Google: in HubSpot, connect the ad accounts (Marketing → Ads → Connect account), then create an audience from a contact list. HubSpot keeps that audience in sync with the active list automatically, adding new matches and removing anyone who leaves it (like a guest who opts out). Add the Exclusion list as an excluded audience on every campaign.
